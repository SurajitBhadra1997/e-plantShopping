# e-plantShopping

## Project Overview

**e-plantShopping** is a React-based e-commerce application for browsing and purchasing plants online.

The application provides users with an easy way to explore different plants, view product information, add plants to a shopping cart, update quantities, and manage their selected products before checkout.

## Features

* Browse available plants
* View plant details and pricing
* Add plants to the shopping cart
* Increase or decrease product quantities
* Remove products from the cart
* View the total number of selected items
* View the total cart price
* Responsive React user interface

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* React Hooks
* Git
* GitHub

## Running the Project Locally

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project:

```bash
cd e-plantShopping
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm run dev
```

or, depending on the React project configuration:

```bash
npm start
```

## Purpose

The **e-plantShopping** project demonstrates the implementation of a simple shopping application using React, including component-based development, state management, event handling, and shopping-cart functionality.
